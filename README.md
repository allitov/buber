# Микросервисное приложение для заказа такси

Итоговая работа по курсу "Разработка серверного программного обеспечения".

## Описание
Сервис моделирует упрощённую платформу заказа такси. 
Пассажир создаёт поездку, система ищет подходящих водителей, назначает поездку, 
обновляет статусы и формирует историю. 
В фоне работает сервис, который обрабатывает очередь заказов и рассылает уведомления.
